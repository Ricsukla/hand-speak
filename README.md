
# HandSpeak 💜

Real-time hand gesture recognition and communication platform.

## Features

- User registration and login
- Secure password hashing
- Real-time webcam streaming
- MediaPipe hand landmark detection
- 10 hand gesture recognitions
- Live FPS and hand count
- Gesture detection history
- Purple aesthetic dashboard

## Technologies

- Python
- Flask
- OpenCV
- MediaPipe
- NumPy
- SQLite
- HTML, CSS and JavaScript

## Installation

1. Clone the repository.
2. Create a virtual environment.
3. Install dependencies.
4. Run the Flask application.

```bash
python -m pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000 in your browser.

## Supported Gestures

LIKE, DISLIKE, OK, PEACE, CALL ME, STOP,
FORWARD, LEFT, RIGHT, I LOVE YOU.
